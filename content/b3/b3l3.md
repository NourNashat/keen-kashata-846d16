## [1] المهام الأدائية

### سؤال: اشرح دور كل من HTML و CSS و JavaScript في بناء صفحة الويب.
تؤدي التقنيات الثلاث أدوارًا مختلفة ومتكاملة في بناء صفحات الويب:
1. **HTML (HyperText Markup Language):** مسؤولة عن تحديد البنية الأساسية لصفحة الويب، مثل العناوين والفقرات والصور والروابط.
2. **CSS (Cascading Style Sheets):** مسؤولة عن تحديد المظهر والتنسيق البصري للصفحة، مثل الألوان والخطوط والأحجام والتخطيط والمسافات.
3. **JavaScript:** مسؤولة عن إضافة السلوك والتفاعلية إلى صفحة الويب، مثل الاستجابة للضغط على الأزرار والتحقق من البيانات المدخلة وتحديث أجزاء من الصفحة.
**مثال توضيحي:** عند إنشاء صفحة ويب تحتوي على زر:
- HTML تنشئ الزر وتحدد وجوده داخل الصفحة.
- CSS تحدد لون الزر وحجمه وشكله.
- JavaScript تحدد ما يحدث عند الضغط على الزر، مثل ظهور رسالة للمستخدم.
وبذلك تتكامل التقنيات الثلاث لبناء صفحة ويب متكاملة من حيث البنية والمظهر والسلوك.

### سؤال: لماذا تُعتبر لغة HTML الدلالية مهمة في بناء صفحات الويب؟
تُعتبر لغة HTML الدلالية (Semantic HTML) مهمة لأنها تستخدم عناصر توضح المعنى والوظيفة لكل جزء من أجزاء صفحة الويب، بدلًا من استخدام عناصر عامة لا توضح طبيعة المحتوى.
ومن أهم فوائدها:
1. مساعدة محركات البحث على فهم محتوى الصفحة وبنيتها بصورة أفضل، مما يساعد في تحسين ظهورها في نتائج البحث (SEO).
2. تحسين إمكانية الوصول (Accessibility)، حيث تساعد برامج قراءة الشاشة والتقنيات المساعدة على فهم أقسام الصفحة والتنقل بينها.
3. جعل كود الصفحة أكثر تنظيمًا ووضوحًا للمطورين.
4. تسهيل صيانة الصفحة وتطويرها مستقبلًا.
**مثال:** استخدام العنصر header لتحديد رأس الصفحة، والعنصر main لتحديد المحتوى الرئيسي، والعنصر footer لتحديد تذييل الصفحة.

### اختيار: لغة HTML مسؤولة عن:
- [ ] المظهر البصري.
- [x] الهيكل الأساسي للصفحة.
- [ ] السلوك التفاعلي.
- [ ] تحسين الأداء.
> HTML تحدد بنية الصفحة وعناصرها، مثل العناوين والفقرات والصور والروابط، بينما CSS مسؤولة عن المظهر وJavaScript مسؤولة عن السلوك التفاعلي.

### اختيار: أي مما يلي من عناصر صفحة الويب الدلالية (Semantic HTML) ما عدا:
- [ ] header
- [x] E-mail
- [ ] main
- [ ] footer
> العناصر header وmain وfooter من عناصر HTML الدلالية، أما E-mail فليس عنصرًا دلاليًا قياسيًا في HTML.

## [1] أداءات منزلية

### سؤال: وضّح كيف يساعد التصميم المتجاوب في تحسين تجربة المستخدم.
التصميم المتجاوب (Responsive Design) هو أسلوب تصميم يجعل تخطيط صفحة الويب يتكيف تلقائيًا مع أحجام الشاشات المختلفة، مثل شاشات أجهزة الكمبيوتر والهواتف الذكية والأجهزة اللوحية.
ويساعد على تحسين تجربة المستخدم من خلال:
1. عرض المحتوى بصورة مناسبة لحجم الشاشة المستخدمة.
2. تسهيل قراءة النصوص دون الحاجة إلى تكبيرها أو تصغيرها باستمرار.
3. ترتيب العناصر والصور بما يناسب مساحة الشاشة.
4. تسهيل التنقل واستخدام الأزرار والروابط على الأجهزة المختلفة.
5. توفير تجربة استخدام مريحة ومتناسقة سواء كان المستخدم يستخدم هاتفًا أو جهاز كمبيوتر.

### سؤال: وضح ما الفائدة من استخدام إطار عمل (Framework) في تطوير الواجهة الأمامية.
إطار العمل (Framework) هو بنية برمجية توفر أدوات وقواعد ومكونات جاهزة تساعد المطورين على بناء تطبيقات الويب بصورة منظمة وأكثر كفاءة.
ومن أهم فوائده:
1. تقليل الحاجة إلى كتابة جميع الأكواد من البداية.
2. توفير مكونات وأدوات جاهزة يمكن استخدامها وإعادة استخدامها.
3. تنظيم الكود وتسهيل صيانته وتطويره.
4. تسريع عملية تطوير تطبيقات الويب.
5. تسهيل بناء تطبيقات كبيرة تحتوي على صفحات ومكونات متعددة.
ومن أمثلته Next.js، وهو إطار عمل مبني على React ويساعد على تطوير تطبيقات الويب.

### اختيار: لغة CSS تُستخدم في:
- [ ] بناء الهيكل.
- [ ] إضافة التفاعل.
- [x] تنسيق المظهر.
- [ ] إدارة قواعد البيانات.
> CSS مسؤولة عن تنسيق المظهر البصري لصفحة الويب، مثل الألوان والخطوط والأحجام والتخطيط.

### اختيار: لغة JavaScript تضيف:
- [ ] العناوين والفقرات.
- [ ] الألوان والخطوط.
- [x] السلوك التفاعلي.
- [ ] عناصر دلالية.
> JavaScript تضيف التفاعلية إلى الصفحة، مثل تنفيذ إجراء عند الضغط على زر أو التحقق من البيانات المدخلة.

## [2] المهام الأدائية

### سؤال: أعط مثالًا على عنصر HTML دلالي واكتب وظيفته.
من أمثلة عناصر HTML الدلالية:
- <header>: يُستخدم لتحديد رأس الصفحة أو رأس أحد أقسامها.
- <nav>: يُستخدم لتحديد منطقة روابط التنقل بين أجزاء الموقع.
- <main>: يُستخدم لتحديد المحتوى الرئيسي للصفحة.
- <footer>: يُستخدم لتحديد تذييل الصفحة أو القسم.
**مثال:** عند تصميم موقع إخباري، يمكن استخدام header لعرض اسم الموقع وشعاره، وmain لعرض الأخبار الرئيسية، وfooter لعرض معلومات الموقع وحقوق النشر.

### سؤال: ناقش كيف تسهم CSS في تحسين المظهر البصري للصفحة.
تسهم لغة CSS في تحسين المظهر البصري لصفحة الويب من خلال التحكم في طريقة عرض العناصر وتنسيقها، ومن أهم استخداماتها:
1. تحديد ألوان النصوص والخلفيات.
2. تغيير أنواع الخطوط وأحجامها وأشكالها.
3. تحديد أحجام العناصر والمسافات بينها.
4. تنظيم تخطيط الصفحة وتوزيع العناصر.
5. تحسين عرض الصفحة على الشاشات المختلفة من خلال التصميم المتجاوب.
وبذلك تجعل CSS صفحة الويب أكثر تنظيمًا وجاذبية وسهولة في الاستخدام، مع الحفاظ على فصل التنسيق عن البنية الأساسية التي تحددها HTML.

### اختيار: عنصر header في HTML الدلالية يُستخدم لـ:
- [ ] المحتوى الرئيسي.
- [ ] التنقل.
- [x] رأس الصفحة.
- [ ] أسفل الصفحة.
> العنصر header يُستخدم لتحديد رأس الصفحة أو رأس أحد أقسامها، وقد يحتوي على عنوان أو شعار أو معلومات تمهيدية.

### اختيار: التصميم المتجاوب يعني:
- [x] ضبط التخطيط وفقًا لأحجام الشاشات المختلفة.
- [ ] استخدام JavaScript فقط.
- [ ] تحسين قواعد البيانات.
- [ ] إخفاء المحتوى غير المهم.
> التصميم المتجاوب يجعل تخطيط الصفحة يتكيف تلقائيًا مع أحجام الشاشات المختلفة لتوفير تجربة استخدام مناسبة.

## [2] أداءات منزلية

### سؤال: ما الفرق بين مكتبة React وإطار Next.js؟
يوجد اختلاف بين مكتبة React وإطار Next.js من حيث طبيعة كل منهما والوظائف التي يقدمها:
**أولًا: React**
- هي مكتبة JavaScript تُستخدم لبناء واجهات المستخدم.
- تعتمد على تقسيم الواجهة إلى مكونات (Components) قابلة لإعادة الاستخدام.
- تساعد على بناء واجهات تفاعلية وتحديث أجزاء الصفحة عند تغير البيانات.
**ثانيًا: Next.js**
- هو إطار عمل مبني على مكتبة React.
- يوفر أدوات وخصائص إضافية تساعد على بناء تطبيقات ويب متكاملة.
- يوفر إمكانات مثل التوجيه (Routing) وتنظيم الصفحات وطرق عرضها.
**الفرق الأساسي:** React مكتبة لبناء واجهات المستخدم، بينما Next.js إطار عمل مبني عليها ويوفر مجموعة من الأدوات والوظائف الإضافية لتطوير تطبيقات الويب.

### سؤال: لماذا يُعتبر نهج الأولوية للجوال مهمًا في التصميم المتجاوب؟
نهج الأولوية للجوال (Mobile-First) هو أسلوب في التصميم يبدأ فيه المطور بتصميم صفحة الويب لتناسب الشاشات الصغيرة مثل الهواتف الذكية أولًا، ثم يوسع التخطيط ويضيف التحسينات لتناسب الشاشات الأكبر مثل الأجهزة اللوحية وأجهزة الكمبيوتر.
وتكمن أهميته في:
1. الاهتمام بتوفير تجربة استخدام مناسبة لمستخدمي الهواتف الذكية.
2. ضمان ظهور المحتوى الأساسي بصورة واضحة على الشاشات الصغيرة.
3. تسهيل استخدام الأزرار والروابط والتنقل عبر الهاتف.
4. تجنب ازدحام الصفحة بالعناصر غير الضرورية.
5. تسهيل توسيع التصميم ليتناسب مع أحجام الشاشات الأكبر.

### اختيار: إطار العمل React يُستخدم لـ:
- [x] بناء واجهات المستخدم بمكونات قابلة لإعادة الاستخدام.
- [ ] إدارة قواعد البيانات.
- [ ] تشفير الاتصال.
- [ ] تحسين الأداء فقط.
> React مكتبة JavaScript تُستخدم لبناء واجهات المستخدم من خلال مكونات مستقلة يمكن إعادة استخدامها في أجزاء مختلفة من التطبيق.

### اختيار: إطار العمل Next.js مبني على:
- [ ] Vue
- [x] React
- [ ] CSS
- [ ] HTML
> Next.js إطار عمل مبني على مكتبة React، ويوفر أدوات إضافية لتطوير تطبيقات الويب وتنظيم الصفحات والتوجيه وطرق عرضها.

## [3] النموذج (B)

### سؤال: اشرح كيف تعمل HTML و CSS و JavaScript معًا لتكوين صفحة ويب متكاملة.
تعمل HTML وCSS وJavaScript معًا لتكوين صفحة ويب متكاملة، حيث تؤدي كل تقنية وظيفة مختلفة:
1. **HTML:** تحدد البنية الأساسية للصفحة، مثل العناوين والفقرات والصور والروابط.
2. **CSS:** تتحكم في المظهر والتنسيق، مثل الألوان والخطوط والأحجام وتخطيط العناصر.
3. **JavaScript:** تضيف السلوك التفاعلي، مثل الاستجابة للضغط على الأزرار والتحقق من البيانات وتحديث أجزاء الصفحة.
**مثال:** عند إنشاء صفحة تسجيل دخول:
- HTML تنشئ حقول إدخال اسم المستخدم وكلمة المرور وزر تسجيل الدخول.
- CSS تنسق الحقول والزر وتحدد الألوان والأحجام.
- JavaScript تتحقق من البيانات المدخلة وتنفذ الإجراءات المطلوبة عند الضغط على زر تسجيل الدخول.
وبذلك تتكامل التقنيات الثلاث لتوفير صفحة ويب تحتوي على بنية منظمة ومظهر مناسب وتفاعل مع المستخدم.

### سؤال: اذكر مثالًا على عنصر HTML دلالي، واشرح فائدته في تحسين الوصول؟
من أمثلة عناصر HTML الدلالية العنصر nav، وهو يُستخدم لتحديد منطقة روابط التنقل داخل الموقع.
وتتمثل فائدته في تحسين إمكانية الوصول من خلال:
1. مساعدة برامج قراءة الشاشة على التعرف على منطقة التنقل.
2. تسهيل انتقال المستخدمين بين أقسام الموقع.
3. توضيح وظيفة الجزء الموجود داخل الصفحة.
4. مساعدة التقنيات المساعدة على فهم بنية الموقع.
**مثال:** يمكن استخدام nav لتجميع روابط الصفحة الرئيسية والأخبار والخدمات واتصل بنا.

### سؤال: اشرح مفهوم «الأولوية للجوال» في التصميم المتجاوب، ولماذا يُستخدم؟
الأولوية للجوال (Mobile-First) هي نهج تصميم يبدأ فيه المطور بإنشاء صفحة الويب لتناسب الشاشات الصغيرة مثل الهواتف الذكية أولًا، ثم يطور التصميم ليتناسب مع الشاشات الأكبر.
ويُستخدم هذا النهج للأسباب التالية:
1. توفير تجربة استخدام مناسبة لمستخدمي الهواتف الذكية.
2. التركيز على المحتوى والوظائف الأساسية التي يحتاج إليها المستخدم.
3. ضمان وضوح النصوص والعناصر على الشاشات الصغيرة.
4. تسهيل توسيع التصميم ليتناسب مع الأجهزة الأكبر.
5. تحسين سهولة التنقل والتفاعل مع الصفحة عبر الهاتف.

### سؤال: اذكر اثنتين من المكتبات والأطر الشائعة لتطوير الويب موضحًا خصائصهما.
من أشهر التقنيات المستخدمة في تطوير الواجهات الأمامية:
**1. React:**
- مكتبة JavaScript لبناء واجهات المستخدم.
- تعتمد على المكونات (Components).
- تسمح بإعادة استخدام المكونات في أجزاء مختلفة من التطبيق.
- تساعد على إنشاء واجهات تفاعلية وتحديث أجزاء الصفحة عند تغير البيانات.
**2. Next.js:**
- إطار عمل مبني على مكتبة React.
- يوفر نظامًا لتنظيم الصفحات والتوجيه (Routing).
- يقدم طرقًا مختلفة لعرض صفحات الويب.
- يساعد على بناء تطبيقات ويب بصورة أكثر تنظيمًا وتكاملًا.

## [3] النموذج (C)

### سؤال: كيف تُضيف JavaScript التفاعلية إلى صفحة الويب مع مثال عملي؟
تضيف JavaScript السلوك التفاعلي إلى صفحة الويب من خلال تنفيذ أوامر برمجية استجابةً لإجراءات المستخدم، مثل الضغط على الأزرار أو إدخال البيانات أو اختيار عناصر معينة.
ومن أمثلة استخداماتها:
1. تنفيذ إجراء عند الضغط على زر.
2. التحقق من صحة البيانات المدخلة في النماذج.
3. عرض رسائل تنبيه للمستخدم.
4. تحديث جزء من الصفحة دون الحاجة إلى إعادة تحميل الصفحة بالكامل.
**مثال:** في صفحة ويب تحتوي على زر بعنوان «عرض النتيجة»، يمكن استخدام JavaScript لتنفيذ عملية معينة وعرض النتيجة للمستخدم عند الضغط على الزر.

### سؤال: اذكر فوائد استخدام HTML الدلالية بالنسبة لمحركات البحث.
تساعد HTML الدلالية محركات البحث على فهم محتوى صفحة الويب وبنيتها بصورة أفضل، وذلك من خلال استخدام عناصر توضح وظيفة كل جزء من الصفحة.
ومن فوائدها:
1. توضيح المحتوى الرئيسي للصفحة باستخدام main.
2. تحديد أقسام التنقل باستخدام nav.
3. تحديد رأس الصفحة باستخدام header.
4. تحديد التذييل باستخدام footer.
5. تسهيل فهم بنية المحتوى وفهرسته بواسطة محركات البحث، مما يساعد على تحسين ظهور الصفحة في نتائج البحث (SEO).

### سؤال: وضح كيف يساعد التصميم المتجاوب في تحسين تجربة المستخدم على الهواتف الذكية.
يساعد التصميم المتجاوب على تحسين تجربة المستخدم على الهواتف الذكية من خلال جعل تخطيط صفحة الويب يتكيف مع حجم شاشة الهاتف، وذلك عن طريق:
1. ضبط أحجام النصوص لتكون سهلة القراءة.
2. ترتيب العناصر بما يناسب مساحة الشاشة الصغيرة.
3. ضبط الصور لتناسب أبعاد الشاشة.
4. جعل الأزرار والروابط سهلة الاستخدام باللمس.
5. تقليل الحاجة إلى التمرير الأفقي أو تكبير وتصغير الصفحة باستمرار.
وبذلك يستطيع المستخدم تصفح الموقع والتفاعل معه بسهولة من خلال الهاتف الذكي.

### سؤال: ناقش دور إطار العمل Next.js في تطوير تطبيقات الويب الحديثة.
يُعد Next.js إطار عمل مبنيًا على مكتبة React، ويساعد المطورين على بناء تطبيقات ويب حديثة بصورة منظمة وأكثر كفاءة.
ومن أهم أدواره:
1. توفير نظام للتوجيه (Routing) يساعد على تنظيم صفحات التطبيق والتنقل بينها.
2. توفير طرق مختلفة لعرض صفحات الويب.
3. تنظيم التطبيق وتقسيمه إلى صفحات ومكونات.
4. الاستفادة من مكونات React القابلة لإعادة الاستخدام.
5. توفير أدوات وخصائص إضافية تقلل العمل المتكرر وتسهل عملية تطوير التطبيقات وصيانتها.
وبذلك يساعد Next.js على بناء تطبيقات ويب أكثر تنظيمًا وتكاملًا بالاعتماد على مكتبة React.
