# حل التقييمات

```
npm i
npm run dev      # تطوير (أي تعديل في content/ بيعمل reload)
npm run check    # تحقق من المحتوى فقط
npm run build    # check + بناء dist/
npm test         # اختبارات التحميل الكسول
```

## إضافة درس
1. أنشئ `content/<bookId>/<lessonId>.md` (اسم الملف = id الدرس، والترتيب حسب الاسم).
2. لو الباب جديد: أضفه في `content/books.json` وأيقونته في `src/icons.js`.

```md
---
id: b5l1
no: الدرس الأول
title: عنوان الدرس
---

## [1] المهام الأدائية

### سؤال: نص السؤال المقالي
الإجابة (قوائم، **غامق**، جداول بـ |)

### اختيار: نص السؤال الموضوعي
- [ ] خيار
- [x] الصحيح (واحد بالظبط، من 2 إلى 4 خيارات)
> التفسير (اختياري)

## [review]
|المفهوم|الوظيفة
|...|...
```
الأخطاء بتظهر برقم السطر، والبناء بيفشل لو الشكل غلط.
